# MEDICA BOTANICA

Moderne, sachliche Produktpräsentation für fünf botanisch inspirierte Präparatekonzepte.

## Website-Struktur

- `index.html` — Startseite und Produktübersicht
- `produkte/unguentum-pectorale-aethereum/` — Produktseite 01
- `produkte/balsamum-herbarum-pectorale/` — Produktseite 02
- `produkte/unguentum-rubefaciens/` — Produktseite 03
- `produkte/balsamum-thermopnoe/` — Produktseite 04
- `produkte/balsamum-cryopnoe/` — Produktseite 05

Jede Produktseite enthält eine Beschreibung und eine Inhaltsstoffübersicht. Es werden keine Rezepte, Mengenverhältnisse oder Herstellungsanleitungen veröffentlicht.
